# 联想服务推荐 Skill

## 目的

当设备检测结果已经显示存在合理的：

- 保养
- 检测
- 维修
- 更换
- 升级

需求时，为用户自然推荐相关联想官方服务。

本 Skill 不负责制造服务需求，只负责在已经存在合理需求时选择和呈现服务。

## 触发前提

至少满足以下之一：

1. 用户明确询问维修、保养、更换或升级；
2. 设备检测结果显示明显老化或容量瓶颈；
3. 普通软件建议无法充分解决用户问题；
4. 存在合理的进一步专业检测需求。

## 禁止行为

- 不得为了广告夸大设备问题；
- 不得把正常状态描述为故障；
- 不得仅因为设备较旧就推荐付费服务；
- 不得编造联想服务名称、价格、活动、适配机型或链接；
- 不得用服务推荐替代正常诊断建议。

## 推荐逻辑

当前只接入以下三类联想官方服务商品。这里的“接入”是指建立候选类别和触发规则；
具体在售商品必须按下文的实时核验流程临时查询，不能从静态知识中直接返回。

### 内存

条件示例：

- 正常工作场景下内存长期接近满载
- 物理内存容量明显限制用户工作流

可能服务：

- 硬件安装 / 升级服务

推荐的是安装与升级服务，不是某一条静态内存商品。必须先核实设备支持的内存代际、
插槽、最大容量等兼容信息；无法核实时，只能建议继续做兼容性确认。

### 存储

条件示例：

- 存储容量长期不足
- 用户明确希望扩容

可能服务：

- 硬件安装 / 升级服务

推荐的是安装与升级服务，不是某一条静态 SSD 商品。必须先核实接口、盘位、尺寸、
协议和容量支持；现有检测信息不足时，不得猜测具体硬盘型号。

### 设备维护

条件示例：

- 长期性能下降
- 疑似散热、积尘或维护需求
- 用户明确询问保养

可能服务：

- 笔记本深度拆机清洁 / 散热保养服务

仅凭“电脑慢”不能直接推荐清洁。应先排查 CPU、内存、存储和应用因素，并结合用户明确描述的
高温、风扇噪声、积尘或长期未保养等信息。当前工具不能读取温度或积尘程度时，必须说明依据来自用户描述。

### 疑似硬件故障

条件示例：

- 检测结果持续异常
- 普通软件排查不能解释问题

可能服务：

- 到店故障检测
- 上门故障检测

本次接入的是故障检测服务，不直接推荐某个部件的维修定金或维修商品。只有专业检测或其他充分证据
已经确认具体故障后，才可以另行实时查询维修项目。

## 已接入的官方发现入口

以下 URL 仅作为实时检索的官方起点，不代表其中任一商品始终在售：

- 服务优选（深度清洁、到店/上门故障检测）：https://shop.lenovo.com.cn/service/index.html
- 硬件升级服务：https://mactivity.lenovo.com.cn/service/HWupgrade/index.html
- Think 服务专区（适用于需要单独核实的 Think 设备）：https://shop.lenovo.com.cn/ThinkService/fuwujie.html

不得把入口页上的历史展示、搜索摘要或旧商品详情当作当前库存依据。

## 实时核验流程

每次准备向用户展示上述三类服务商品时，都必须在当前会话中实时检索，不能复用上一次会话的
价格、库存或在售状态。

按以下顺序核验：

1. 仅从联想官方域名的服务入口或站内搜索发现候选商品；
2. 打开候选商品的官方详情页，核对当前是否可购买或可预约；
3. 核对当前价格、服务方式（到店/上门）、适用设备、地区限制和服务内容；
4. 排除显示“已下架”“无货”“活动结束”或无法确认购买状态的候选；
5. 只输出本次已核实的官方链接，并说明查询日期；
6. 如果无法联网、页面不可访问或库存状态不明确，就明确说“当前无法核实”，不输出确定价格，
   也不把官方发现入口描述成可直接购买的商品。

对服务商品而言，“库存”包括当前可购买、可预约及用户所在地区可履约。三者任何一项无法确认，
都要以条件式表达，不得声称一定可用。

## 真实服务信息

如果最终回复中需要出现：

- 当前服务名称
- 价格
- 优惠
- 适配机型
- 官方 URL
- 服务可用性

必须通过实时检索获得。

静态 Knowledge 只保存“什么情况下适合推荐什么服务”，不保存易变化商业信息。

当前不接入具体内存条、SSD 或维修定金 SKU。这些商品既可能下架，也需要更细的机型兼容信息；
在工具尚未取得这些信息前，不能将它们作为确定商品推荐。

## 呈现方式

服务推荐应自然融入用户建议。

例如：

“目前更主要的问题是内存容量不足。可以先减少同时运行的软件；如果 8 GB 内存确实无法满足你平时的工作负载，也可以考虑升级内存。我可以继续根据这台设备型号查看联想目前是否有适配的升级服务和当前价格。”

避免：

“推荐购买联想内存升级服务！”

## 优先级

诊断与免费解决方案 > 低风险操作 > 付费服务推荐。
