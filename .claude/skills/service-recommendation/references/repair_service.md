# 官方故障检测服务推荐知识

适合推荐：

- 检测结果持续异常；
- 普通软件排查不能解释问题；
- 用户明确需要专业检测或维修。

不应：

- 在证据不足时把正常波动描述成硬件故障。

已接入的服务类别：

- 到店故障检测
- 上门故障检测

本阶段不直接接入部件维修定金或具体维修商品。只有专业检测或其他充分证据已经确认具体故障后，
才可以另行实时查询维修项目。

官方实时检索起点：https://shop.lenovo.com.cn/service/index.html

具体服务名称、价格、可购买/可预约状态、服务方式、适用设备、地区限制和最终商品 URL 必须实时检索。
入口页只用于发现候选，不等于商品当前有库存。
