# 内存升级服务推荐知识

适合推荐的情况：

- 用户明确询问升级内存；
- 正常工作场景下内存长期接近满载；
- 当前物理内存容量明显限制用户工作流。

不适合推荐：

- 仅一次高内存占用；
- 明显由临时打开过多应用导致。

已接入的服务类别是“硬件安装 / 升级服务”，不是某一条静态内存商品。

推荐前必须先核实设备支持的内存代际、插槽、最大容量等兼容信息。现有检测信息不足时，
只能建议进一步做兼容性确认，不得猜测内存型号。

官方实时检索起点：https://mactivity.lenovo.com.cn/service/HWupgrade/index.html

具体服务名称、适配性、价格、可购买/可预约状态、地区限制和最终商品 URL 必须实时检索。
入口页只用于发现候选，不等于商品当前有库存。
