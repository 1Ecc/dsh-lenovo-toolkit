# Wi-Fi 网络体检报告 Skill

## 目的

当用户希望查看、保存或分享 Wi-Fi 检测结果时，生成网络体检报告。普通联网问题仍使用 `wifi_diagnosis`；只有用户需要图片、动态报告、体检卡或分享材料时加载本 Skill。

## 主要工具

- `wifi_generate_report`：快速生成静态 SVG 图片；
- `wifi_generate_html_report`：采样一段时间并生成动态 HTML；
- `network_monitor`：用户只想观察实时波动、不需要报告文件时使用。

报告工具内部复用：

- `wifi_get_status`
- `wifi_diagnose`

不要为了生成报告再次重复调用相同检测工具。

## 工作流程

1. 用户需要快速图片或方便分享时，调用 `wifi_generate_report`。
2. 用户提到动态、波动、上传/下载、延迟趋势或详细界面时，调用 `wifi_generate_html_report`；未指定时使用默认 30 秒。
3. HTML 报告采样期间向用户说明正在检测，不要重复启动另一次采样。
4. 将返回的 SVG 图片或 HTML 资源链接直接展示给用户。
5. 用一两句话说明总体状态和最重要建议，不重复抄写整份报告。
6. 如果工具返回 `partial`，说明缺失字段或采样限制；返回 `unsupported/error` 时改为文字说明，不编造曲线。

## 图片内容边界

报告只展示：

- 当前总体状态；
- Wi-Fi 网卡 → 无线连接 → 网关 → DNS → Internet 链路；
- 信号、链路速率和网关延迟；
- 根据检测结果生成的保守建议；
- 检测时间和快照限制。

HTML 报告还可以展示：

- 5～60 秒的上传/下载吞吐变化；
- 网关延迟、抖动和丢包；
- 采样数据对应的异常时段。

默认隐藏 SSID、IP、DNS 和网关地址。不要在图片外补充这些字段，除非用户明确提出并理解隐私影响。

## 诊断原则

- 网关、DNS 或外网异常不等于无线网卡损坏；
- 当前正常不代表历史上没有偶发问题；
- 上传/下载曲线表示 Wi-Fi 网卡实际吞吐，不等于宽带测速；
- 信号低于 40% 只标记为“信号较弱”，不判断硬件故障；
- 不自动建议重置网络、修改 DNS 或付费维修；
- 只有持续的设备侧异常且普通排查无法解释时，才转入服务推荐。

相关 Wi-Fi 判读资料位于本 skill 的 `references/`，只在报告结果需要解释时读取。
