# 能力域：已安装应用查询

回答「装没装某某软件」「装的是哪个版本」。

| 项 | 值 |
|---|---|
| 工具 | `app_list` |
| skill | `.dsh/skills/app-diagnosis/` |
| 平台 | 仅 Windows |
| 数据源 | Windows 卸载注册表（HKLM / HKLM WOW6432Node / HKCU 三处 Uninstall 键） |

## 参数

| 参数 | 约束 |
|---|---|
| `query` | **必填**，2～100 字符，大小写不敏感的子串匹配 |
| `limit` | 1～50，默认 10 |

## 边界：为什么强制要关键词

**这是隐私边界，不是参数校验。** 一台机器上装了什么软件是高度敏感的画像信息，
「按名查询」和「拉全量清单」是两件事。空关键词等于后者，所以在碰 PowerShell **之前**
就返回 `invalid_query` 并附警告「不允许无关键词枚举全部软件」。
`test/tools/app.test.js` 对空串、空格、单字符和超长串都有断言。

## 判读注意

结果来自卸载注册表，所以**免安装程序和部分商店应用不会出现**——
`app_list` 返回空**不能**推断为「没装」。这句限制在 `warnings` 里，判读时必须转述。
